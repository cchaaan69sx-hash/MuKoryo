01

About

香害とは

香害（こうがい）とは、柔軟剤や合成洗剤、香水、整髪料などに含まれる 香料などの化学物質によって、まわりの人が健康被害や不快感を受けることをいいます。

香りの感じ方は人それぞれ。使っている本人には「ほのかないい香り」でも、 敏感な人にとっては、同じ空間にいるだけで体調をくずす原因になることがあります。

近年は香りが長続きする製品が増え、教室、職場、電車、病院など、 自分では選べない場所で香りを浴びてしまうことが問題になっています。

Note — 国も注意をよびかけています

2021年、消費者庁・文部科学省・厚生労働省・経済産業省・環境省の5省庁が連名で、 啓発ポスター「その香り 困っている人もいます」を作成し、香りへの配慮をよびかけました。

香りの感じ方には個人差があり、自分にとって快適な香りでも、ほかの人には不快に感じられることがある──という内容です。

02

Symptoms

こんな症状が
出ることがあります

香りによる不調は「気のせい」ではありません。

  • 頭痛・めまいHeadache
  • 吐き気・食欲不振Nausea
  • 息苦しさ・せき・のどの痛みBreathlessness
  • 鼻水・くしゃみ・目のかゆみIrritation
  • 集中力の低下・倦怠感Fatigue
  • 動悸・皮膚のかゆみPalpitation

化学物質過敏症（MCS）について

さまざまな化学物質に反応して、多様な症状が出る状態を「化学物質過敏症」と呼びます。 重い場合は、外出や通学・通勤が難しくなることもあります。 だれでも発症する可能性があるといわれており、香りを控えることは未来の自分を守ることにもつながります。

※ 体調に不安がある方は、医療機関にご相談ください。

03

Sources

身近な香りの
発生源

i.

柔軟剤・洗剤

香害の原因として特に多く挙げられます。衣類に香りが残るため、着ている人のまわりにも長時間広がります。

ii.

香りのマイクロカプセル

こすれると香りがはじける極小のカプセル。香りを長持ちさせる一方、空気中に飛散することも心配されています。

iii.

香水・整髪料・化粧品

直接肌や髪につけるため香りが強く、エレベーターや電車など狭い空間では特に影響が大きくなります。

iv.

制汗剤・ボディケア

スプレータイプは周囲に広がりやすく、更衣室や教室での使用が問題になることがあります。

v.

芳香剤・消臭剤

トイレや車内、店舗などに置かれ、利用する人が避けられない香りになりがちです。

vi.

ルームフレグランス

アロマ・お香・キャンドルなど。集合住宅では換気口などを通じて隣の部屋に届くこともあります。

04

Re-think

体臭の
とらえ方を変える

「いい香りに癒やされる」──それが、いまの常識です。
だから、においが気になると、香りを足して上書きしようとします。

でも、香りを足すほど、まわりのだれかを苦しめてしまうことがあります。 そこで私は、発想を逆にしました。体臭を香りで「かくす」のではなく、 体の内側から「ととのえる」。

like a peach.

目指すのは、桃のような、やわらかな香り。

若い世代の肌から感じられる甘い香りのもとは、「ラクトンC10」「ラクトンC11」という成分だと報告されています。 ラクトンC10はキンモクセイ、ラクトンC11は桃の香りをつくる成分としても知られ、ココナッツにも似た甘さをもつ香りです。

i.

お酢をとる

毎日の習慣に、少しのお酢を。水や炭酸水で薄めて飲むほか、りんご酢にヨーグルトをかけて食べるのもお気に入りです。

ii.

ヨーグルト＋カシスエキス

ヨーグルトにカシスエキスを合わせて、一緒にとります。

iii.

ラクトフェリンをとる

たんぱく質の一種「ラクトフェリン」を、食品やサプリメントでとり入れます。

iv.

湯船につかって汗をかく

シャワーだけで済ませず、湯船につかって汗を流します。よい汗をかく習慣が、においの少ないさらりとした汗につながると言われています。

香りを足さない。自分の香りを、ととのえる。

※ ここで紹介しているのは、私が実践している方法です。効果の感じ方には個人差があり、 体臭が変わることが十分に確かめられているわけではありません。 お酢は必ず薄めて飲み、持病のある方や薬を飲んでいる方は、医師に相談してください。

05

How to start

無香料生活の
はじめ方

一度にすべてを変えなくても大丈夫。できるところから、ひとつずつ。

  1. 01

    柔軟剤を見直す

    まずは影響の大きい柔軟剤から。使わなくても、洗剤の量を適量にして、しっかりすすぐだけで十分ふんわり仕上がります。気になる場合は「無香料」表示のものを。

  2. 02

    洗剤を「無香料」に

    ラベルの「無香料」表示を確認しましょう。「微香」「ほのかな香り」は香料入りです。石けん系の洗剤も選択肢のひとつです。

  3. 03

    消臭は「香りでかくさない」

    においは香りで上書きするより、換気・洗濯・乾燥で元から断つのが基本。重曹やクエン酸など、香りのないお手入れも活用できます。

  4. 04

    身だしなみを見直す

    シャンプー、整髪料、制汗剤、日焼け止めなども無香料の製品があります。使い切ったタイミングで少しずつ切り替えましょう。

  5. 05

    香りは「自分だけ」が楽しむ

    香りを楽しみたいときは、自宅など自分だけの空間で。人と会う日や公共の場では控えめに、が思いやりのマナーです。

Laundry

香りに頼らず、においを残さない洗い方

i.

たっぷりの水で洗う

節水コースは洗剤が偏り、汚れやすすぎ残しの原因に。水はケチらず、たっぷり使います。

ii.

裏返しにして洗う

汗や皮脂がつくのは、肌にふれる内側。裏返して洗うと、においのもとが落ちやすくなります。

iii.

4つの素材を使い分ける

香りでかくさず、汚れとにおいのもとを落とす。下の4つを、目的に合わせて使います。

  • 重曹弱アルカリ性。皮脂や汗の汚れ、こもったにおいに。
  • クエン酸酸性。すすぎに加えると、石けんカスなどアルカリ性の汚れをすっきり。
  • 酸素系漂白剤しみついたにおいや黄ばみに。ぬるま湯でのつけ置きがおすすめ。
  • 焼きミョウバン水に溶かして、すすぎや消臭スプレーに。汗のにおい対策に。

※ 塩素系の漂白剤とは絶対に混ぜないでください（酸性のクエン酸と混ざると有毒なガスが出ます）。 重曹とクエン酸は打ち消し合うので、同時ではなく別々に使います。衣類の洗濯表示も確認しましょう。

Action

みんなで
できること

  • 香りの強い製品を使っていないか、ふり返ってみる
  • 「香りで困っている人がいる」ことを、家族や友人に話してみる
  • 香りで体調をくずした人がいたら、「気のせい」と言わずに話を聞く
  • 買い物のときに「無香料」を選ぶ。選ぶ人が増えると、商品も増えます
  • 身だしなみ規定に「香りへの配慮」を加える
  • 共用スペースの芳香剤・消臭スプレーの使用を見直す
  • 香りがつらい人が相談しやすい窓口をつくる
  • 席の配置やテレワークなど、柔軟な対応を検討する
  • おたよりなどで、保護者に柔軟剤・香料への配慮をよびかける
  • 給食着や共用物の洗濯に、無香料の洗剤を使う
  • 教室の換気をこまめに行う
  • 香りで体調をくずす子どもの席の配慮や、相談体制をととのえる
  • つらいときは無理をせず、その場をはなれて換気のよい場所へ
  • 症状やきっかけをメモしておくと、相談するときに役立ちます
  • 化学物質過敏症にくわしい医療機関に相談する
  • 製品に関する困りごとは、消費者ホットライン「188」（いやや！）で相談できます

07

Q&A

よくある質問

「いい香り」なのに、なぜ問題なの？

香りを「いい」と感じるかどうかは人によって違います。また、香りそのものではなく、香料などに含まれる化学物質に体が反応してしまう人もいます。使う人が気づかないところで、まわりの人が困っていることがあるのです。

柔軟剤を使わないと、ゴワゴワになりませんか？

洗剤を入れすぎない、すすぎを十分にする、干す前に衣類をよく振ってシワをのばす、といった工夫でやわらかく仕上がります。タオルは乾燥機を使うとふんわりしやすくなります。

「無香料」と「微香」はどう違うの？

「微香」「ほのかな香り」は、香料が入っている製品です。香りを避けたい場合は「無香料」の表示を確認しましょう。なお「無香料」でも、原料由来のにおいがある場合があります。

汗やにおいが気になるときは？

香りでかくすより、こまめに汗をふく、通気性のよい衣類を選ぶ、無香料の制汗剤を使う、などがおすすめです。衣類のにおいは、洗濯後に早く乾かすことで防ぎやすくなります。

身近な人の香りがつらいとき、どう伝えたらいい？

相手を責めるのではなく、「実は香りで頭が痛くなってしまう体質で…」と自分の状況として伝えると、受け止めてもらいやすくなります。5省庁の啓発ポスターを見てもらうのもひとつの方法です。
